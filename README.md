# Comunicar+

O **Comunicar+** é uma plataforma focada em assistência à fala e exercícios fonéticos para suporte ao desenvolvimento da comunicação.

---

## 🚀 Tecnologias Utilizadas

* **Frontend:** React / TypeScript / CSS3 / HTML5
* **Backend / API:** Node.js / TypeScript
* **Hospedagem / Deploy:** Vercel

---

## 🛠️ Funcionalidades Principais

* **Exercícios Fonéticos:** Atividades focadas na articulação e desenvolvimento da fala.
* **Interface Acessível e Intuitiva:** Design otimizado e responsivo para facilidade de navegação.
* **Acompanhamento de Progresso:** Módulos para prática contínua de fala e pronúncia.

---

## 🌐 Acesso Online

A aplicação está implantada e disponível diretamente no navegador através da **Vercel**:
